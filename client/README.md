# My To-Do List — Client

React + Vite front-end. See the root [`README.md`](../README.md) for the full project guide.

- `npm run dev` — start Vite on `http://localhost:5173`
- `npm run lint` — oxlint
- `npm run build` — production build

Environment: copy `.env.example` to `.env` and set `VITE_API_URL` to the API base URL
(e.g. `http://localhost:5000/api`).
